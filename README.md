# 时间规划局

使用C#和WPF构建的日程规划桌面应用。每次查看一个日期，所有日期的标记分别保存。横向时间轴默认显示06:00—22:00，通过底部导航条可查看00:00—24:00，日程文字通过连线显示在时间轴下方。

## 启动

在安装.NET10Desktop Runtime的Windows电脑上，双击`release/DayPlanner.exe`。

源码运行：

```powershell
dotnet run
```

## 使用

- 启动时显示当天日期，点击日期右侧的日历按钮可选择任意一天，查看或创建当天的标记。
- 单击时间轴空白位置，创建一个时间点事件。
- 在空白位置横向拖动，创建一段日程；松开后填写内容。
- 拖动日程色条或文字卡片，整体调整时间。
- 拖动色条左右端点，调整开始或结束时间。
- 双击卡片编辑；右键或点击卡片省略号打开编辑、删除菜单。
- 编辑窗口直接点击颜色方块选择标记颜色；点击“＋”通过RGB滑块或颜色代码添加自定义颜色，添加后自动保存至色板。
- 编辑日程时勾选“提前提醒”，选择提前分钟数，默认5分钟，也可手动填写1至1440分钟。提醒以标记的开始时间为准，时间点和时间段均支持。
- 工具栏切换5分钟、10分钟网格，创建和拖动自动吸附。编辑窗口支持手动输入精确分钟。
- Ctrl+滚轮以鼠标所在时间点为中心缩放，上滚放大、下滚缩小；可视范围为2至24小时。Shift+滚轮或鼠标中键拖动平移。
- 底部全天缩略轴可拖动视区和左右边界，也可点击跳转。
- 重叠日程和相邻文字卡片自动错层，纵向滚动查看。

|快捷键|操作|
|---|---|
|Ctrl+N|创建事件|
|Ctrl+Z / Ctrl+Y|撤销 / 重做|
|Ctrl+S|重试保存|
|Enter|编辑已选日程|
|Delete|删除已选日程|
|Esc|取消拖动或关闭编辑窗口|
|Ctrl+Enter|在编辑窗口保存|

每个日期的日程、事件和撤销记录独立管理。日期标题表示当前查看的日期，编辑窗口也显示标记所属日期。右上角时钟按电脑本地时间实时更新，今天的时间轴显示当前时间指示线。自定义色板和网格设置在各日期间共用。

## 托盘与通知

应用在Windows通知区域显示常驻图标，Windows也可能将图标放在右下角“显示隐藏的图标”中。点击窗口关闭按钮时，可选择“最小化到托盘”或“退出程序”，并可勾选“记住我的选择”。主界面或托盘右键菜单中的“关闭时最小化到托盘”可调整已记住的行为。最小化到托盘后，单击托盘图标恢复窗口，右键菜单中的“退出”会完整关闭应用。再次启动程序会恢复已运行的窗口；更新程序后请先完整退出旧版再打开新版。

提醒在程序运行期间触发，窗口隐藏到托盘时也会发送Windows系统通知。点击提醒可以打开对应日期。每项安排在同一开始时间和提前量下提醒一次，提醒记录会保存。多项同时到期时合并提示。程序启动或电脑唤醒后，仍处于提前提醒时间段内的安排会补发提醒。通知的实际展示和声音由Windows通知设置控制。

## 数据保存

全部日期的标记统一保存到`%LOCALAPPDATA%/DayPlanner/schedule.json`，以`yyyy-MM-dd`为日期键分别记录，切换日期时保留其他日期的数据。每次完成编辑后自动保存，上一次成功保存的完整内容位于同目录的`schedule.json.bak`。保存采用临时文件及原子替换。加载异常时保留原文件，并显示提示。

旧版单日数据会在首次打开新版时归入当天，迁移前的完整文件额外保存在`schedule.json.v1.bak`。

## 构建

```powershell
dotnet build -c Release
dotnet publish -c Release --no-self-contained -o release
```

`--demo`使用示例安排及程序目录中的独立演示数据文件。
